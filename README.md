# rpe
La Revista Procesos Económicos es una revista electrónica arbitrada, con frecuencia de publicación anual, que edita el Grupo de Investigación Omega Beta Gamma del Instituto de Investigaciones Económicas de la Facultad de Ciencias Económicas de la Universidad Nacional Mayor de San Marcos (Lima, Perú).
